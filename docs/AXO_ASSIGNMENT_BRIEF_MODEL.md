# AXO Assignment Brief Model

Common fields: service, subject, title/topic, academic level, country or university system, word count, deadline, time, timezone, referencing style, required sources, instructions, files and voluntary contact details.

Dissertation adds degree level, chapter requirement, methodology, proposal status, supervisor feedback and data availability. SOP adds purpose, target programme, background, experience, goals and draft availability. Editing, originality and formatting add document type and review depth.

Only file metadata and private asset IDs are retained in the browser draft. File contents remain in private storage. Final submission requires explicit consent and confirmation.
