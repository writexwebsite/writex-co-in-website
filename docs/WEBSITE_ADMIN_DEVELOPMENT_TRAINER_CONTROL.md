# Website Admin Development Trainer Control

Authority: Founder Delivery Trainer correction

Website Admin remains the employee identity, employment, Academy access, operational reporting and entitlement source of truth. Creating or editing an active Development / Operations employee with Academy role `TRAINER` produces the following Academy profile:

- Operational role: Delivery Trainer
- Academy role: Trainer / Evaluator
- Learning role: None
- Lesson access: all 26 Development lessons and 266 sublessons, read only
- Assessment review scope: all Development / Operations learner assessments
- Trainer assignment to self: none
- Learning assignment: none

The profile retains the employee's explicit reporting relationship where applicable, but reporting hierarchy does not broaden assessment authority. Trainer assignment remains a separate relationship and is not assigned to the Trainer themself.

The only Academy writes granted by the Trainer role are claim assessment review, save review draft, complete assessment review and escalate assessment review. Website Admin must not present controls that imply own learning, repair, reassessment, certification, hierarchy, curriculum or Sales authority.

Role or entitlement changes continue through normal Website Admin controls and Academy sync. A Trainer role correction preserves the same employee identity and historical evidence while revoking active Academy sessions so the next login loads the corrected claims.
