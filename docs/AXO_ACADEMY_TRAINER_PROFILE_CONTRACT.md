# AXO Academy Trainer Profile Contract

Version: 1.0  
Authority: Founder Delivery Trainer correction

For an active `DEVELOPMENT_OPERATIONS` employee with Academy role `TRAINER`, Website Admin returns:

- Academy role: `TRAINER_EVALUATOR`
- Learning role: `NONE`
- Lesson access: `ALL_26_DEVELOPMENT_LESSONS_READ_ONLY`
- Assessment review scope: `ALL_DEVELOPMENT_OPERATIONS_LEARNER_ASSESSMENTS`
- Learning assignment: `null`
- Trainer assignment to self: `null`
- Reporting relationship: the explicit Website Admin relationship, when applicable
- Allowed Academy writes: claim review, save review draft, complete assessment review and escalate assessment review

Website Admin remains the identity, access, reporting and entitlement source of truth. The contract does not grant repair, reassessment, certification, hierarchy, assignment, curriculum or Sales authority.
