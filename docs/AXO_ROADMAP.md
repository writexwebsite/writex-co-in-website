# AXO Roadmap

- Phase 1: audit, typed rules, approved asset pipeline and deterministic selector.
- Phase 2: ambient launcher, contextual prompts, responsive concierge and preferences.
- Phase 3: adaptive brief, summary, private upload and manual quote request.
- Phase 4: existing order, revision, human handoff and privacy-safe analytics.
- Phase 5: optional approved-knowledge retrieval after provider, policy and security approval.
- Phase 6: production telemetry, standalone compressed mascot assets, malware provider, retention automation and performance budgets in CI.

AI mode remains disabled until an approved provider, data-processing policy, retrieval boundary, evaluation set and kill switch are available.
