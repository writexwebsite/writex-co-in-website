# AXO Student Journey

1. AXO remains ambient and silent. A page-specific suggestion appears once per session after a delay.
2. The visitor opens the concierge and chooses a new requirement, service guidance, existing-order support, revision, or human contact.
3. New enquiries choose one of the six public WriteX services. AXO asks only the relevant fields.
4. The visitor adds deadline, timezone, instructions and optional private files.
5. AXO generates an editable, copyable summary and requires contact consent.
6. The visitor explicitly confirms submission. The normal quote API creates the lead; complex scope remains manual review.
7. If submission or upload fails, AXO preserves entered details and offers configured WhatsApp/contact channels.
8. Existing customers are directed to authenticated client login. An unauthenticated handoff never reveals order data.
9. Returning visitors resume session drafts by default; device persistence requires explicit opt-in.
