# Festival Studio Kaise Set Karein - Step-by-Step Admin Guide

Last verified: 10 August 2026  
Verified release: `20260810T135001Z-independence-quality-admin-guide-v1`

## Quick Checklist

Festival select -> Variant select -> Recommended Setup -> Header -> Ground -> Footer -> AXO -> Effects -> Save -> Preview -> Apply/Schedule only when approved

## Sabse Pehle

- Festival Studio kholiye: **Super Admin -> Website Experience -> Festival Studio**.
- Top status mein dekhiye ki public website par kaunsa festival active hai.
- **Private Preview** sirf Admin ko dikhta hai. **Apply Now** ya **Schedule** ke bina public website nahi badalti.
- Sound default mein OFF rakhiye. Visitor ko khud Play karna chahiye.

## 1. Festival Select Karein

1. **Configure** tab kholiye.
2. **Festival** dropdown se event choose karein.
3. Festival badalte hi purane festival ka Header, Ground, AXO aur Effects carry forward nahi hone chahiye.
4. Ownership row mein Festival, Selected Design aur Ownership ek hi event dikhna chahiye.

Expected result: Selected festival ka naam URL aur ownership panel dono mein same rahe.

## 2. Design Variant Select Karein

1. **Design variant** dropdown ya visual card se approved design choose karein.
2. Card par **Selected** aur **approved** status check karein.
3. **Preview** se exact selected artwork kholiye.
4. `Selected Design` aur preview ka design same hona chahiye.

## 3. Login Preview Dekhein

1. **Preview & Activate** tab kholiye.
2. Client Desktop, Client Mobile, Employee Desktop aur Employee Mobile alag-alag check karein.
3. Har route par sirf ek real functional form hona chahiye.
4. WriteX logo aur tagline Light, Dark aur Auto mode mein readable honi chahiye.
5. Hero sharp ho; fake form, duplicate logo, blur wall ya horizontal scrolling nahi hona chahiye.

## 4. Recommended Setup Use Karein

1. **Use Recommended Festival Setup** button dabaiye.
2. Success message ka wait karein.
3. Is shortcut se approved Header, Ground, Footer, AXO, Ambient aur Feature recommendations fill hoti hain.
4. Sound OFF hi rehta hai.
5. Recommended Setup configuration ko lock nahi karta; har visible section baad mein badal sakte hain.

## 5. Header Pack Choose Karein

1. **Decorate Header** tab kholiye.
2. Complete Header Pack ka preview dekhein.
3. **Use Complete Pack** dabaiye.
4. Header rail navigation ke neeche edge-to-edge honi chahiye.
5. Logo, menu, Login aur Get Quote par overlap nahi hona chahiye.

Remove test: **Remove Pack** dabaiye; normal WriteX Header lautna chahiye. Phir **Restore Previous** se selected Header wapas layein.

## 6. Page/Ground Decoration Select Karein

1. **Decorate Ground & Page Bottom** tab kholiye.
2. Assignment region mein **Ground & Page-bottom Decoration** select karke Ground composition check karein.
3. Complete Ground Pack ka preview dekhein aur **Use Complete Pack** dabaiye.
4. Asset content, buttons aur chatbot ko cover nahi karna chahiye.
5. Desktop, tablet aur mobile par lower-page placement verify karein.

## 7. Footer Decoration Select Karein

1. Isi section mein assignment region ko **Footer Decoration** par badaliye.
2. Complete Footer Pack ka preview dekhein.
3. **Use Complete Pack** dabaiye.
4. Footer links, contact details aur chatbot usable rehne chahiye.
5. Divider crisp ho; stretch, pixelation ya horizontal overflow nahi hona chahiye.

## 8. AXO Select Karein

1. **Decorate AXO** tab kholiye.
2. Approved AXO composition select karein.
3. Face, chest branding aur belt branding clear honi chahiye.
4. Hand prop declared anchor se attached ho; floating prop approve na karein.
5. AXO chatbot se alag rahe aur mobile par clip na ho.

## 9. Ambient Effect Choose Karein

1. **Festival Scene Effects** kholiye.
2. **Ambient Effect** mein maximum ek subtle effect select karein.
3. Effect buttons ko block na kare aur pointer events OFF hon.
4. Mobile aur reduced-motion fallback zaroor check karein.

## 10. Feature Effect Choose Karein

1. **Feature Effect** region kholiye.
2. Maximum ek occasional effect select karein.
3. Feature effect continuously content par nahi chalna chahiye.
4. Mobile par reduced version aur reduced-motion mein static fallback verify karein.

## 11. Sound ON/OFF Karein

1. **Sound** tab kholiye.
2. Normal setup mein Sound OFF rakhiye.
3. Sound enable karna ho to visible Play/Mute control aur low volume verify karein.
4. Autoplay kabhi enable na karein.

## 12. Save Karein

1. **Save Studio** ya **Save Draft** dabaiye.
2. Button par loading complete hone dein; double-click na karein.
3. Green success message ka wait karein.
4. Error aaye to Apply na karein; visible explanation aur Reference ID note karein.

## 13. Refresh Ke Baad Verify Karein

1. Browser refresh karein.
2. Festival, Variant, Header, Ground, Footer, AXO aur Effects dobara check karein.
3. Exact selections same rehni chahiye.
4. Sound state aur target surfaces bhi same honi chahiye.

## 14. Private Preview Dekhein

1. **Refresh Private Preview** dabaiye.
2. `Fresh Preview Ready` aur matching Snapshot code check karein.
3. Homepage, Client aur Employee previews kholiye.
4. Desktop, tablet, 430px, 390px aur 360px views check karein.
5. Light, Dark, Auto aur reduced-motion check karein.
6. Draft badalne ke baad purana preview stale ho jata hai; naya preview banana zaroori hai.

## 15. Apply Now Kab Use Karein

1. Apply sirf fresh matching Private Preview ke baad karein.
2. Homepage, Client Login, Employee Login, Light, Dark aur mobile check karein.
3. Required review confirmations tick karein.
4. **Apply Now** immediate public change karta hai; final confirmation dhyan se padhein.
5. Success ke baad anonymous website khol kar preview controls count `0` verify karein.

## 16. Schedule Kab Use Karein

1. Future event ke liye **Schedule** tab kholiye.
2. Asia/Kolkata start aur end time verify karein.
3. Existing schedule conflict check karein.
4. End time ke baad Normal WriteX Website automatic restore hona chahiye.
5. Aaj public karna ho to Schedule ke badle Apply Now use karein.

## 17. Remove Kaise Karein

1. Header, Ground, Footer, AXO ya Effect ka relevant visible section kholiye.
2. Active pack par **Remove Pack** dabaiye.
3. Sirf wahi region normal WriteX fallback par jana chahiye.
4. Doosre selected regions change nahi hone chahiye.
5. Save aur Private Preview se result verify karein.

## 18. Restore Previous Kaise Karein

1. Remove ya replacement ke turant baad **Restore Previous** dabaiye.
2. Previous exact pack/version wapas aana chahiye.
3. Save ke baad refresh karein.
4. Private Preview mein restored region verify karein.

## 19. Festival Completely Turn Off Karein

1. **Festival Status** ya **Preview & Activate** kholiye.
2. **Turn Off Festival** dabaiye.
3. Confirmation mein preserved setup notice padhein.
4. Confirm karne par public Normal WriteX Website dikhni chahiye, lekin festival draft/history saved rehni chahiye.
5. Festival ko baad mein dobara activate kiya ja sakta hai.

## 20. Website Normal Kaise Karein - Emergency Reset

Use one action: **RESTORE NORMAL WEBSITE**.

1. Festival Studio mein **Restore Normal Website** dabaiye.
2. Confirmation mein Header, Ground, Footer, AXO, Effects, Sound aur Login surfaces sab listed hone chahiye.
3. Confirm karein.
4. Homepage, Client Login aur Employee Login normal WriteX state mein verify karein.
5. Is action ko emergency/broken partial state ke liye use karein; ordinary temporary deactivation ke liye **Turn Off Festival** use karein.

## Advanced: Asset Upload Aur Review

1. Advanced Festival Management se approved workflow ka uploader kholiye.
2. Login Hero ke liye clean artwork upload karein: logo, form, buttons ya fake UI embedded na ho.
3. Exact version, checksum, source aur compatible regions check karein.
4. Founder Visual Review mein isolated aur real-context preview dekhein.
5. Desktop/tablet/mobile aur Light/Dark sab review karein.

## Advanced: Approve, Improve Aur Reject

- **Approve:** sab mandatory gates pass, score 85/100 ya zyada, exact checksum safe.
- **Needs Improvement:** concept sahi hai lekin fixable visual/placement issue hai; note mandatory hai.
- **Reject:** wrong concept, unsafe cultural/brand use, duplicate, unlicensed source ya major redesign required.
- **Approve & Next:** exact reviewed version approve karke next asset kholta hai.

Corrected version approve karte waqt original history preserve honi chahiye. Naye checksum ko nayi version ke roop mein review karein; approved file overwrite na karein.

## Common Problems

- **Selected design nahi dikh raha:** fresh Preview banayein; Festival/Variant ownership check karein.
- **Draft changed after preview:** draft save hua hai; Refresh Private Preview karein.
- **AXO nahi dikh raha:** Decorate AXO mein active pack aur Festival AXO enabled state check karein.
- **Header missing:** Header region selected ho; Hero region mein galat assignment na ho.
- **Ground/Footer missing:** correct Assignment region choose karein aur page bottom tak scroll karein.
- **Effect move nahi ho raha:** Motion enabled aur reduced-motion setting check karein.
- **Sound nahi chal raha:** visitor ko Play dabana hota hai; autoplay allowed nahi hai.
- **Dark mode wrong:** Light/Dark preview aur protected logo treatment check karein.
- **Saved but active nahi:** Save sirf private draft hai; public ke liye fresh Preview ke baad Apply/Schedule chahiye.
- **Generic error:** Apply na karein. Safe reference ID aur failed action record karein.

## Final Admin Rule

Easy path: Festival -> Variant -> Recommended Setup -> Visual checks -> Save -> Fresh Private Preview -> Apply/Schedule only after approval.

Safe path: kisi bhi mismatch, cultural doubt, broken source, floating AXO prop, wrong region ya stale preview par public activation rok dein.
